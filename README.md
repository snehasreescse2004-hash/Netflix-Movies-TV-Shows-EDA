# Netflix Movies and TV Shows – Exploratory Data Analysis

## Project Overview

In this project, I performed Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset using Python, Pandas and Matplotlib.

The main aim of this project is to understand the Netflix content library by analysing different types of content, genres, ratings, countries and movie durations.

## Dataset Information

- **Dataset:** Netflix Movies and TV Shows
- **Source:** Kaggle
- **Rows:** 8,807
- **Columns:** 12
- **File Format:** CSV

**Dataset Link:** https://www.kaggle.com/datasets/shivamb/netflix-shows

## Tools and Libraries Used

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Analysis Performed

1. Dataset structure and overview
2. Missing value analysis
3. Summary statistics
4. Movies vs TV Shows analysis
5. Top 10 countries on Netflix
6. Content released over the years
7. Top 10 genres
8. Movie duration distribution
9. Content ratings analysis
10. Movies and TV Shows comparison by release year

## Key Findings

- Netflix has 6,131 Movies and 2,676 TV Shows.
- TV-MA is the most common content rating.
- The United States has the highest number of titles.
- Dramas, International Movies is the most common genre combination.
- The year 2018 has the highest number of titles based on release year.

## Project Outcome

Through this project, I learned how to explore a real-world dataset, identify missing values, calculate summary statistics and create visualizations using Python.

This project helped me improve my understanding of data analysis and visualization.
